# Cloned voices

Drop a clean, mono `.wav` of 10–20 seconds here and it appears in the
Casting panel under its file name. A file called `Default_Narrator_Male.wav` is
selected for the Narrator automatically. For OmniVoice, add the exact words
spoken in it as `NAME.wav.txt` beside it.

Pocket-TTS reproduces the speaker *and* the recording quality, so record in
a quiet room with no music. The volume doesn't matter: every generated line
is leveled to the same loudness, so quiet and loud recordings sound alike.

The voices in this folder are committed with the code, so anyone who clones
the repo gets them. Only add recordings you have the right to share.
