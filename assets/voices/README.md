# Cloned voices

Drop a clean, mono `.wav` of 10–20 seconds here and it appears in the
Casting panel under its file name. A file called `Default_narrator.wav` is
selected for the Narrator automatically.

Pocket-TTS reproduces the speaker *and* the recording quality, so record in
a quiet room with no music.

`.wav` files in this folder are git-ignored: voice samples are personal
recordings and should not be published with the code.
